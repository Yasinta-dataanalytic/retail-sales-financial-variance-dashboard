# End-to-End Retail Sales Performance & Financial Variance Dashboard
### Sales & Financial Performance Analytics

An Excel-based analytics solution that takes messy retail sales data through
cleaning, modeling, and automation to a decision-ready dashboard comparing
actual performance against budget.

> **Status:** 🚧 In progress — raw datasets and data dictionary uploaded; workbook, data model, DAX, and VBA to follow.

## Planned Scope
| Component | Tools |
|---|---|
| Data cleaning | Power Query |
| Data model | Power Pivot (star schema) |
| KPIs & variance | DAX measures |
| Automation | VBA / Macros |
| Dashboard | PivotTables, Slicers, Charts |

## Data Note
All data is **simulated** for portfolio purposes. Stores, products, people, and figures are fictional. See [`01_data/data_dictionary.md`](01_data/data_dictionary.md).
